# Snake Game

A classic Snake game implemented in **C++** that runs directly in the console.

## Features

- Real-time snake movement
- Random fruit generation
- Fruit spawning protection (fruit never appears on the snake's head or body)
- Snake growth after eating fruits
- Score tracking system
- Collision detection:
  - Self-collision
  - Wall collision
- Portal movement through the borders
- Pause and resume functionality
- Win condition when the snake fills the whole board
- Console-based game over and win screens


## Technologies

- C++
- Standard Template Library (STL)
- Windows Console API

## Run Requirements

- C++ compiler (such as GCC, MinGW, or MSVC)
- Windows operating system
